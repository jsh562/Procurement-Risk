# UX Requirements Quality: Line Detail and Traceability
**Created**: 2026-07-30 | **Feature**: [spec.md](../spec.md)

## Completeness

- [ ] CHK001 Is there a requirement obliging the textual equivalent to be composed from the same published figures the plot renders from, given FR-014 enumerates its five contents but no requirement forbids a second, separately composed copy — the path research.md names as where a point estimate re-enters unnoticed? [Completeness, Spec §FR-014, §FR-017; Research §Accessible equivalents]
- [ ] CHK002 Does any requirement oblige the equivalent to convey the spread and tail length the fifty marks convey, given FR-014's list reaches only the eightieth percentile and the residual mass while US1 states the reader can see how long the tail runs? [Completeness, Spec §FR-014, §US1, §SC-005]
- [ ] CHK003 Is the obligation Scope states — the equivalent available to every reader rather than to assistive technology alone — carried by a requirement, given FR-014 rules out alt text and FR-015 fixes placement and disclosure without naming who the equivalent is available to? [Completeness, Spec §Scope, §FR-014, §FR-015]
- [ ] CHK004 Is there a requirement fixing how a reader is told a displayed source is synthesized at the moment the page is shown, given FR-022 binds "wherever such a record is listed or its page displayed" and a byte stream can carry the distinction only outside the reader's view? [Completeness, Spec §FR-022, §US2]
- [ ] CHK005 Does any requirement state the reader-facing consequence FR-020a records — that the reader is handed a whole document positioned at a page rather than the page — including what the view states when the position is not honoured? [Completeness, Spec §FR-020a, §FR-020]
- [ ] CHK006 Is there a requirement giving a reader who cannot read the streamed source an equivalent route to the cited value, given FR-018 lists the extracted span in the record list but no requirement makes that span the accessible equivalent of the page FR-020 requires displayed? [Completeness, Spec §FR-018, §FR-020, §FR-020a]
- [ ] CHK007 Is the reader's return path from a displayed source specified — whether the source replaces or accompanies the view, and how a reader using a keyboard gets back to the line — given Scope excludes navigation chrome and FR-020 requires the page displayed? [Completeness, Spec §FR-020, §Scope]
- [ ] CHK008 Is an accessibility standard and conformance level named anywhere in the requirements, or are FR-015, FR-040 and FR-043 the whole of the obligation this view is judged against? [Completeness, Spec §FR-015, §FR-040, §FR-043]
- [ ] CHK009 Does any requirement fix how the bounded forms FR-041 mandates are rendered as words, given a rendering that drops the inequality states the flat certainty the bounded form exists to prevent, and FR-041 adopts the delivered form without the announcement obligation that accompanies it? [Completeness, Spec §FR-041, §FR-040]
- [ ] CHK010 Is there a requirement that the census FR-024 publishes names its population and its no-interval declaration in reader-facing words, given the figure counts every linked record the active resolution run carries and therefore reads, on a line carrying two records, as a statement about that line? [Completeness, Spec §FR-024, §SC-010]
- [ ] CHK011 Is the per-field confidence FR-018 requires distinguished in reader-facing terms from the frequencies published beside it, given it is a self-reported score rather than a probability and renders as one more number about the same line? [Completeness, Spec §FR-018, §FR-041]
- [ ] CHK012 Is there a requirement stating what the reader is told when a session need-by adjustment is in force — that the figures answer a what-if rather than the record — given Scope excludes the control and FR-005 names only the effective date? [Completeness, Spec §FR-005, §Scope; Plan §AD-008]
- [ ] CHK013 Is the wording of the states FR-042 enumerates committed as data beyond the identity states, given FR-026 commits copy for the unresolved case alone while FR-043 rests its decidability on distinctness being asserted over committed copy? [Completeness, Spec §FR-026, §FR-042, §FR-043]
- [ ] CHK014 Do the annotation states carry the obligation FR-026 places on the identity state — naming what the state withholds — given a reader meeting the at-or-before-anchor state finds the miss mass absent with no stated reason? [Completeness, Spec §FR-042, §FR-026, §FR-006]
- [ ] CHK015 Is there a requirement governing the vocabulary of reader-facing copy, given the reader is stated not to be a statistician while the terms the spec uses for its own figures — quantile, percentile, posterior, census, residual mass — have no stated lay rendering? [Completeness, Spec §Assumptions, §Glossary]
- [ ] CHK016 Is the navigation target FR-035 fixes required to carry an accessible name identifying the line, given the target is an existing worklist field and the worklist's row content is closed against adding an element? [Completeness, Spec §FR-035, §SC-016]

## Clarity

- [ ] CHK017 Is FR-015's "within the same region as the figures it describes" reducible to an observable property — a shared container, reading-order adjacency, or a visual area — given neither the requirements nor the Glossary define "region" while FR-038's whole domain is now fixed by one? [Clarity, Spec §FR-015, §FR-038, §Glossary]
- [ ] CHK018 Does FR-015 close the set of mechanisms it forbids, or does "hover, focus, expansion, click or panel" leave placement below the fold, an off-screen node, or a block hidden by a media query admissible? [Clarity, Spec §FR-015]
- [ ] CHK019 Does FR-040 require one carrier serving both readings, or is it satisfied by text present only in the accessibility tree, leaving a sighted reader with colour or position as their sole carrier? [Clarity, Spec §FR-040, §FR-015]
- [ ] CHK020 Is "a phrase" in FR-043 defined, and is its no-substring rule applied within each of FR-042's three scopes or across all of them, given SC-018 scopes indistinguishability to "any scope" while FR-043 binds every state against every other? [Clarity, Spec §FR-043, §SC-018, §FR-042]
- [ ] CHK021 Is FR-004's "adjacent to each frequency" scoped to the two labelled quantiles alone or to every frequency the view publishes — the per-mark share, the miss mass in both directions, the residual mass, and each cumulative band? [Clarity, Spec §FR-004, §FR-001, §FR-005, §FR-008]
- [ ] CHK022 Does FR-001's "that share stated in words beside the figure" fix a form — a natural frequency naming both the count and the population it counts, or a percentage — given the misreading research.md measured is a denominator that lost its noun? [Clarity, Spec §FR-001; Research §Discrete outcomes versus continuous density]
- [ ] CHK023 Is the reference class required to name a population a coordinator would recognise rather than the artifact it was computed from, given the Glossary says "comparable orders" while the committed constant the plan reconciles to says "out of 100 lines like this one"? [Clarity, Spec §FR-004, §Glossary; Plan §AD-005]
- [ ] CHK024 Do any requirements establish the distribution, mass, evidence and covariate regions FR-038's domain is defined by, so that a reviewer can locate a region's boundary without reading the implementation? [Clarity, Spec §FR-038, §FR-042]
- [ ] CHK025 Is FR-038's locus decidable for a value rendered in more than one place — the as-of date, which its *date* class admits and its artifact-identification carve-out excludes? [Clarity, Spec §FR-038, §FR-013]
- [ ] CHK026 Is FR-017's "any single value as the expected outcome" reducible to a decidable property in the way FR-037 reduces a forbidden date to one carrying no stated proportion? [Clarity, Spec §FR-017, §FR-037]
- [ ] CHK027 Is FR-045's "mark its own figures as such" decidable between one mark carried once for the view and a mark carried by each figure? [Clarity, Spec §FR-045]
- [ ] CHK028 Does FR-042's section-scoped composition rule fix what the reader is told, given a covariate panel with one withheld value among three carries the same section state as one in which every value is withheld? [Clarity, Spec §FR-042, §FR-031]
